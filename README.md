# FAQ Chatbot

## Description
A simple FAQ Chatbot built using HTML, CSS, and JavaScript. The chatbot answers user questions by finding the most similar FAQ using Cosine Similarity.

## Features
- Simple Chat Interface
- FAQ Matching
- Cosine Similarity
- Fast Response
- Responsive Design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project.
2. Open the folder in VS Code.
3. Run index.html using Live Server.
